# 图片元素编辑器（Image Element Editor）

把任意图片作为画布底图，在上面叠加并自由编辑文本、图片、矩形、圆形元素。全部在本机浏览器完成，不上传文件。

## 能力

- **添加元素**：文本、图片（本地上传）、矩形、圆形。
- **X/Y 移动**：拖拽元素，或属性面板输入精确坐标；方向键微移（Shift 大步）。
- **缩放**：选中元素后拖 8 个控制点；Shift 等比；属性面板可输入宽高。
- **旋转**：拖顶部圆点旋转（Z 轴），属性面板可输入 -180~180 度。
- **倾斜**：属性面板输入 X/Y 倾斜角，做 3D 透视效果（预览为 CSS transform，导出为 Canvas 近似斜切）。
- **Z 层级**：属性面板「置顶/上移/下移/置底」，或右侧图层列表点击选中。
- **改内容**：双击文本直接编辑；属性面板改文本内容、字号、颜色、粗细、斜体、对齐；形状改填充色。
- **撤销重做**：Ctrl+Z / 工具栏按钮。
- **导出**：合成所有元素为一张 PNG；工程可保存/载入为 JSON。

## 使用方式

1. 插件详情页 →「打开界面」。
2.（可选）点「载入底图」换成自己的图片；默认是一张白底画布。
3. 点工具栏添加元素 → 在画布上拖拽/缩放/旋转 → 右侧改属性。
4. 点「导出 PNG」下载成品。

## 技术说明

- 单文件 index.html，内联 CSS/JS，零外部依赖。
- DOM 呈现编辑态（CSS transform 支持 rotateX/Y/Z），导出用 Canvas 2D 逐元素重绘。
- 沙箱 iframe 内运行，不访问宿主存储、不发网络请求。
