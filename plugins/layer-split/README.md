# 图片元素编辑器 · Image Element Editor

把图片当画布，在上面叠加并自由编辑元素。本地处理，不上传。

| 文件 | 作用 |
|---|---|
| `plugin.json` | 清单，`uiHtml: index.html` |
| `index.html` | 单文件编辑器（内联 CSS/JS） |
| `SKILL.md` | 技能说明 |
| `README.md` | 本说明 |

操作：拖动画布元素移动，拖 8 个控制点缩放，拖顶部圆点旋转，右侧面板改内容/坐标/尺寸/角度/颜色/层级。方向键微移，Delete 删除，Ctrl+D 复制，双击文本直接改字。

导出合成 PNG 或保存工程 JSON。v2.0.0 · 2026-11-25
