# 账号中心（登录/注册）· 个人插件

非官方个人插件。提供一个可交互、**可真实登录**的登录/注册界面，运行在插件详情页的隔离沙箱中，通过受控桥接调用账号接口。

## 目录内容

| 文件 | 作用 |
|---|---|
| `plugin.json` | 清单元数据；`uiHtml: "index.html"` 声明界面文件 |
| `index.html` | 单文件登录/注册界面（内联 CSS/JS，含桥接调用逻辑） |
| `SKILL.md` | 供 AI 读取的技能说明 |
| `README.md` | 本说明 |

## 导入与使用

1. 「插件 → 我的 → 导入项目」选择本目录，导入后自动标记为 **personal（个人/非官方）**。
2. 打开该插件详情页 → 点右上角 **「打开界面」** → 在沙箱 iframe 中显示登录/注册表单。
3. 注册成功会显示分配到的账号（`user_000001`），登录成功显示已登录状态并把登录态存插件内 localStorage。
4. 界面文件随插件目录走；导入后改动 index.html，重开详情或刷新即可（读取实时文件，无需重新导入）。

## 界面功能

- 登录 / 注册 切换
- 注册：昵称（≤20）+ 密码（6-64）+ 确认密码 + 协议勾选
- 登录：账号（`user_000001` 格式）+ 密码，支持显示密码
- 邮箱字段：暂不启用（灰显 + 鼠标悬浮禁止符号 🚫）
- 输入长度限制 + 参数化查询防注入

## 桥接原理（真实登录如何实现）

沙箱 iframe（无 `allow-same-origin`）不能直接调主应用接口。本插件通过受控桥接完成登录：

```
iframe (postMessage) → 父窗口校验来源+注入pluginKey → POST /api/plugin-bridge/call
   → 后端查远程白名单 → 校验通过则代理调用 /api/auth/* → 结果回传 iframe
```

- 白名单：`ekstai/uiw/plugin-acl.json`（仓库描述即「白名单」，token 仅服务端 .env 持有）。
- 当前授权：`local-账号中心-登录-注册-99bddd` → 仅 `/api/auth/register`、`/api/auth/login`。
- 远程可随时增减权限；远程不可达时用本地缓存，无缓存则全部拒绝（fail-closed）。
- **自动驱逐**：一旦本插件的 key 从白名单移除，应用内 30 秒内会自动卸载（DB 记录、MCP 注册、界面缓存、
  以及本目录都会一并清除——目录移到 `%APPDATA%/agnes-chat-app/plugin-trash/` 可恢复）。进入插件页也会立即校验。

## 安全边界

- ✅ 可交互、可校验、可真实注册/登录
- ✅ 插件无法伪造 pluginKey（父窗口注入）、无法调白名单外接口、无法访问主应用 DOM/cookie
- ❌ 仍不能访问主应用 localStorage / 其他接口（设计如此，最小权限）

## 数据

- 用户库：Neon PostgreSQL，连接串在本地 `.env` 的 `NEON_DATABASE_URL`。
- 账号按注册顺序分配（`user_000001`），密码 bcrypt 哈希，用户 ID 为 UUID。
